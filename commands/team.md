---
description: [team] 팀 자동 배정 — 프로젝트를 분석해 알맞은 팀팩을 골라 provision까지 실행
---
현재 프로젝트(또는 $ARGUMENTS 로 지정한 폴더)에 알맞은 에이전트 팀을 배정해. 절차:

1. **후보 확인**: `agent-team teams` (없으면 `~/agent-team/agent-team.sh teams`)로 사용 가능한 팀팩 목록과 인원을 확인한다.
2. **프로젝트 파악**: 대상 폴더를 직접 읽어 성격을 파악한다 — README.md, CLAUDE.md, package.json, pubspec.yaml, requirements.txt, 폴더 구조. (스크립트의 `--auto` 감지보다 깊게 본다 — 이 커맨드를 쓰는 이유다.)
3. **판단**: 프로젝트 성격(모바일/웹/AI/트레이딩/핀테크/마케팅/기타)을 판정하고 팀팩을 고른다. 팀팩만으로 부족한 역할이 있으면 `--need 역할=설명` 으로 보강한다.
   - 애매하면 두 후보의 차이(포함 에이전트)를 비교해 근거와 함께 결정한다. 그래도 반반이면 사용자에게 한 번만 물어라.
4. **실행**: `agent-team provision <폴더> --team <선택한 팩> [--need ...]` 를 실행하고, 결과(배정/신규습득/총원)를 보고한다.
5. **검증**: `agent-team list <폴더>` 로 로스터를 출력해 보여준다.

주의: 이미 팀이 구성된 폴더(.claude/agents 에 .md 존재)면 현재 로스터를 먼저 보여주고, 교체가 필요한지 확인 후 `--prune` 여부를 판단한다. 사용자가 폴더를 안 줬으면 현재 작업 폴더를 대상으로 한다.

대상: $ARGUMENTS
