# UI Refine — AI 디자인 슬롭을 어휘로 잡는다

핵심(Paul Bakaus의 impeccable에서 착안): AI 디자인이 어색한 건 **어휘가 없어서**다.
"더 낫게"가 아니라 **정확한 리파인 명령**으로 컴포넌트를 다듬는다. 각 명령은 시각적으로 무엇을 뜻하는지 규칙이 있다.

## 리파인 어휘 (컴포넌트에 적용하는 명령)

- **Quieter (조용하게)** — 시각적 노이즈를 줄인다. 불필요한 테두리·그림자·구분선 제거, 장식 대비 낮추기,
  여백 늘리기, 중복 라벨 삭제. "요소가 서로 소리치지 않게."
- **Bolder (대담하게)** — 위계를 강하게. 크기 점프를 키우고, **하나의 초점**에만 무게(굵기·색)를 몰고,
  간격을 결단력 있게. 밋밋함을 깬다(단, 초점은 하나만).
- **Distill (증류)** — 정보를 나르지 않는 건 다 뺀다. 중복 제거, 장식 아이콘 컷, 유사 요소 병합.
  "이게 없으면 의미가 사라지나?" 아니면 삭제.
- **Polish (연마)** — 미세 정렬. 그리드·간격 스케일·라운드 반경 일관화, 숫자는 `tabular-nums`,
  포커스 상태·호버·비활성 상태 정리. 픽셀 단위 완성도.
- **Adapt (적응)** — 브랜드/맥락에 맞춘다. 프로젝트 디자인 토큰(색·타이포·간격) 적용, 기존 컴포넌트와 정합.
  design-inspiration 무드보드나 디자인시스템이 있으면 그걸 따른다.

사용 예: "이 카드에 Quieter + Polish", "히어로는 Bolder, 나머지는 Distill".

## AI 슬롭 클리셰 차단 목록 (지정 없으면 피한다)
- 크림색(#F4F1EA)+세리프 디스플레이+테라코타 악센트 조합
- 근검정 배경에 산성 그린/버밀리언 한 방
- 보라→파랑 그라디언트 히어로 on 화이트
- Inter/Space Grotesk를 "안전빵"으로 남발
- 이모지를 섹션 마커로
- 전부 가운데 정렬, 모든 카드 `rounded-lg`, 라운드 카드에 악센트 바/레일
- 거대한 플래시 히어로(대부분 화면은 필요 없음)

## 원칙
- **대담함은 한 곳에만** 쓰고 나머지는 조용히. 악센트가 바탕과 싸우면 채도를 낮추거나 유사색으로.
- 접근성·브랜드 정합은 항상 우선(대비·터치 타깃·포커스 상태).
- 리파인은 **작게, 하나씩** 적용하고 결과를 본다(수술적 변경).

## 우리 팀 흐름과의 연결
- `/uidesign`(design-inspiration으로 레퍼런스 찾기) → 시안 생성 → **ui-refine로 다듬기** → design-lead 게이트(접근성·정합) 순.
- 실무 디자이너(rakwan-designer·ui-ux-designer)와 design-lead가 이 어휘를 공유해 피드백을 정확히 주고받는다.
