# Design Inspiration — "스타일만 말하면 Pinterest 찾아서 그 방향으로 디자인" (자동)

**원칙: 사용자는 스타일만 말한다. 에이전트가 알아서 Pinterest를 검색해 실제 핀·보드 레퍼런스를 찾고 무드보드를 만든 뒤 그 방향으로 디자인한다. URL 요청 금지(없어도 스스로 검색).**

## ⚠️ 먼저 알아야 할 현실 (이 스킬의 설계 근거)
Pinterest는 로그인하지 않은 봇의 **핀 이미지 직접 열람을 차단**한다(핀 페이지·이미지 = 403 / 로그인월, 헤드리스 브라우저도 로그인월). Dribbble·Behance도 마찬가지. **그래서 "이미지를 자동으로 열어 픽셀을 본다"는 경로는 시도하지 않는다** — 실전에서 항상 실패하기 때문.

대신 **실제로 되는 것**을 주력으로 삼는다:
- ✅ **WebSearch로 `site:kr.pinterest.com`** → 실제 핀·보드가 제목·설명·연관검색어와 함께 나온다(로그인 불필요). 여기서 스타일 신호를 추출한다.
- ✅ **핀 URL을 무드보드로 사용자에게 제시** → 사용자는 브라우저에 로그인돼 있어 그 URL을 바로 눈으로 본다.
- ✅ **사용자가 핀/보드 URL이나 스크린샷을 주면** → 그때만 그 이미지를 직접 분석(가장 정확, 유일한 실제-이미지 경로).

## 입력 해석
사용자 말("미니멀한 핀테크 홈", "파스텔 톤 온보딩", "다크모드 트레이딩 대시보드")을 **영문 검색 키워드 2~4개**로 변환.
예: `fintech app home minimal UI`, `pastel onboarding mobile`, `dark trading dashboard UI`, `mypage profile screen clean`.

## 절차 (항상 이 순서)

### 1. Pinterest 검색 (주력, 항상 실행)
`WebSearch`로 아래를 검색:
- `site:kr.pinterest.com <키워드>`
- 필요 시 `site:pinterest.com <키워드>` 추가
- 한국어 화면명은 그대로도 검색(예: `site:kr.pinterest.com 마이페이지 UI`)

상위 핀·보드 **5~10개**를 확보하고, 각각에서 스타일 신호를 뽑는다:
- 제목·보드명·설명·연관검색어의 무드/컬러/레이아웃 용어
- 반복되는 패턴(예: "minimal", "pastel", "card grid", "dark", "glassmorphism")

막히거나 결과가 빈약하면 폴백: `site:dribbble.com <키워드>`, `site:behance.net <키워드>`.

### 2. 무드보드 표 작성 (사용자 확인용)
행마다 `핀/보드 URL + 제목 + 차용할 요소(무드/컬러 방향/레이아웃/컴포넌트)`.
- URL은 **실제 검색으로 나온 것만** 넣는다(추측 URL 금지).
- 사용자가 그 URL을 열어 직접 확인하도록 안내한다.

### 3. 사용자 제공 이미지가 있으면 우선 (선택)
사용자가 특정 핀/보드 URL 또는 스크린샷을 주면 그것을 **최우선 레퍼런스**로 삼고, 이미지를 직접 열어(Read/WebFetch) 팔레트·레이아웃·컴포넌트를 픽셀 단위로 분석한다.

### 4. 디자인 산출
추출한 방향으로:
- 컬러 토큰(HEX)·타이포 스케일·간격
- 컴포넌트 스타일(카드·버튼·차트·내비)
- 핵심 화면 시안(레이아웃·구성) 설명 또는 HTML/artifact 시안
- `canvas-design`·`brand-guidelines`·`theme-factory` 스킬과 연계해 실제 산출물 생성

## 산출물 형식
1. **무드보드 표**: 실제 핀 URL + 차용 요소.
2. **디자인 방향 요약**: 무드/컬러/레이아웃 3~5줄.
3. **디자인 산출**: 토큰·컴포넌트·시안.

## 원칙
- **참고이지 복제 금지**: 무드·패턴·방향만 차용(저작권·상표).
- **정직**: 검색 제목·스니펫에서 패턴을 추론한 것임을 밝히고, 확정 판단이 필요하면 핀 URL을 사용자에게 제시해 눈으로 확인하게 한다. 없는 것을 본 척하지 않는다.
- 접근성(대비 4.5:1·터치타깃)·브랜드 정합은 레퍼런스보다 우선한다.
