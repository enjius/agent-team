# Design Inspiration (Pinterest 우선)

**언제**: 앱 화면·UI·비주얼·디자인시스템 작업을 시작하기 전 (디자인을 바로 그리기 전에 이 절차를 먼저 수행).

## 절차
1. **키워드화**: 대상 도메인·화면·톤을 검색어로. 예) "fintech app dashboard dark", "onboarding illustration minimal", "투자 앱 홈 UI".
2. **Pinterest 우선 조사**:
   - WebSearch: `site:kr.pinterest.com <키워드>` 또는 `site:pinterest.com <키워드>`.
   - 또는 검색 URL 제시: `https://kr.pinterest.com/search/pins/?q=<키워드>`.
   - 차단/로그인으로 직접 열람이 막히면 Dribbble·Behance로 폴백: `site:dribbble.com <키워드>`, `site:behance.net <키워드>`.
   - 사용자가 특정 Pinterest 핀/보드 URL을 주면 그걸 최우선 참고.
3. **패턴 추출 (5~10개 레퍼런스)**: 레이아웃 그리드, 컬러 팔레트(HEX 추정), 타이포 스케일, 컴포넌트 스타일(카드·버튼·차트), 인터랙션·모션.
4. **무드보드 표 작성**: 행마다 `소스 URL + 차용할 요소`. 무엇을 왜 참고하는지 근거.
5. **디자인 산출**: 추출한 방향으로 토큰·컴포넌트·시안 설명을 생성. `canvas-design`·`brand-guidelines`·`theme-factory` 스킬과 연계.

## 원칙
- **참고이지 복제 아님**: 패턴·방향·무드만 차용, 특정 디자인 그대로 베끼기 금지(저작권·상표).
- 이미지를 직접 못 볼 땐 검색 제목·스니펫으로 패턴을 추론하고, **핀 URL을 사용자에게 함께 제공**해 눈으로 확인하게 한다.
- 접근성(대비·터치타깃)·브랜드 정합은 레퍼런스보다 우선한다.
